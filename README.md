# Voxel Lab #01 : Clicker Game (Pilot Project)

## About This Project

This repository hosts the **pilot project** of the Voxel Lab format.

Its purpose is to test our short-cycle collaborative workflow: live prototyping sessions, direct peer collaboration, and zero mandatory homework.

## Challenge Overview

* **Type:** Incremental / Clicker game

* **Format:** Minimum viable playable prototype (MVP)

* **Theme:** Open

* **Tech Stack:** Free choice (no restrictions)

Aside from the community-agreed constraints below, all design and implementation choices are entirely up to each participant.

## Imposed Constraints

1. **Flashy Pink:** Must incorporate the color `#F60887`.

2. **Soundtrack:** Must include a nice background music track.

3. **Stability:** Zero console errors in runtime execution.

## Repository Structure & Workflow

Development takes place directly on the organization's repository, organized by individual directories at the root to avoid merge conflicts:

* `/armand` Individual prototype

* `/celia` Individual prototype

* `/marius` Individual prototype

### Git Guidelines

* Each participant develops inside their own dedicated branch during the sessions.

* Individual directories are merged into the `main` branch at the end of the cycle.

* Participants are encouraged to fork this repository to their personal GitHub profiles to showcase their work.
